# Speaking metadata research — 2026-09-22

Reviewed all 91 stored appearances and attempted all 79 distinct original URLs. Enriched 45 appearances using event agendas, recordings, publisher episode descriptions, and Tim's own event material. The remaining 46 have no new descriptions: unavailable pages and generic current-year homepages do not establish what an old session covered.

## Behavior

Optional descriptions, topic tags, format, session/recording/slides URLs, source URLs, and a source-check date live in the existing speaking Markdown files. Humans can expand “Talk details” in the archive. The same facts are included in `/speaking.md`, `/llms-full.txt`, REST/MCP content and search results, and browser WebMCP summaries. `/llms.txt` retains its compact list. Search now matches researched descriptions and topics. The content API's `/speaking` response now includes the full archive rather than only the page introduction.

No crawler detection or separate factual content was added. No Event JSON-LD was restored; the earlier Search Console decision in `speaking-structured-data.md` still applies. No new dependencies. Existing titles, dates, locations, and original links are preserved; verified session links take precedence for human card titles. Source availability is a check on this date, not a permanent guarantee. A recording URL may be a publisher's episode page with a player.

## Discrepancies and limitations

- Vue Amsterdam 2019 has two very similar records with different dates. Neither was deleted or merged.
- VueDay 2019's official date is April 12; the stored date is April 19. Vue Amsterdam 2020's session is February 20; the stored date is February 18. JSworld's JavaScript day is February 25, 2021; the stored date is February 22.
- We Belong Here's archive lists June 28, 2020 versus stored May 25. Views on Vue lists August 4 versus stored August 5. Kontent Rocks lists publication February 12, 2022 versus stored February 8. Publication dates can differ from recording dates.
- Vue Antwerp's source lists a physical venue in Aalst; the stored location is virtual. Vue Berlin calls the January 2021 talk “I rebuilt my website. Again”. The CityJS London 2023 recording is titled “The Glue Code Monster” and describes remote participation. Original titles and locations remain for owner review.
- The two September 2025 ContentCon filenames disagree with their frontmatter dates. The frontmatter remains authoritative for rendering.
- ReactiveConf's meetup page places another speaker's abstract and bio below Tim's agenda entry. Only Tim's agenda title/duration informed the added summary.
- The ContentCon Austin source is Tim's event vlog, not the talk recording; it is cited only as evidence of the opening performance.
- The iCode episode description was available through the web index, but its live URL now redirects to the creator's new homepage. This is weaker ongoing provenance and may need an archived/replacement episode link.
- The September 30, 2026 certification workshop page establishes workshop content, but does not name Tim; participation comes from the existing owner-authored record. Upcoming descriptions express scheduled content, not proof that an event occurred.
- `gatsbyconf.com` now serves unrelated gambling content. The 2022 record has an official Gatsby article as its preferred session URL; the unverified 2021 original link remains for owner review. `devbreak.io` redirects to unrelated sports streaming for both 2021 entries. These original links should not be treated as evidence about the talks.
